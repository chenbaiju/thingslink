# 接入第一台设备

本教程建立一台教学温湿度设备，目标是在控制台看到对应当前值和历史。需要可登录的账号、设备管理权限、可用接入环境，以及能按协议发送消息的客户端。

## 1 准备项目

在“项目与资源 → 添加项目”填写名称、可创建区域和可选项目描述。创建后到项目列表点击项目条目或“进入”，确认顶部当前项目正确。新项目沿用所属租户订阅，套餐参考卡不是另购流程。

已有项目时直接进入；收到邀请时，先完成邮箱验证并在个人中心明确接受。没有管理权限时请项目管理员完成资源准备。

## 2 定义设备类型

打开“设备开发 → 设备类型”，创建设备类型。添加 `temperature` 与 `humidity` 数值属性，再保存并发布物模型。示例分别表示温度与湿度，单位和有效范围由你的设备规格确定。

发布后核对实际版本号。进入“所有设备 → 创建设备”，选择已发布类型，填写设备名称和项目内唯一设备标识。类型可选，但本教程选择类型以建立明确校验和版本绑定。

## 3 准备连接

打开设备详情的“接入配置”，核对协议、启用状态、配置版本以及部署方提供的地址与 TLS 要求。在“凭据”中生成设备密钥并立即安全保存；秘密只显示一次。具体连接与上报格式见[MQTT 接入](/docs/device/mqtt)。

## 4 上报并核对

订阅自身下行 Topic，再发送属性消息。每次新采集使用新的 UUIDv7 消息 ID 与真实采集时间；同一次消息重试保持 ID、时间和正文一致。

依次核对消息日志、Reported 当前值、原始属性历史。连接成功或 MQTT PUBACK 都不能替代数据核对。曲线没有点时先查时间范围、属性及模型版本。

## 完成标准

你能确认当前项目、设备、发布模型、一次上报的属性值与采集时间相互对应，且没有使用控制台令牌作为设备秘密。

接着完成[温湿度监测实战](/docs/tutorials/environment-monitoring)，把数据连接到告警和看板。
