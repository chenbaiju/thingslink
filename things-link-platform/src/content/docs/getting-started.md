# 快速开始

本文介绍从准备项目与设备到核对上报数据的基本步骤。连接前，请从部署方取得该环境的 MQTT 接入参数和协议说明；本文不包含完整报文教程。

## 开始前

- 准备可登录控制台的账号，以及目标项目的设备管理权限。
- 准备 MQTT 连接地址、端口和 TLS 证书要求，生产连接须校验服务端主机名与 CA。
- 确认项目标识 `projectKey`、设备标识 `deviceKey` 和设备密钥；不要用资源 ID 或控制台登录令牌代替它们。

若尚无账号且部署环境提供注册入口，使用有效邮箱注册，设置至少 10 位密码，并遵循注册页其他提示。提交后按邮件完成邮箱验证，再使用邮箱和密码登录。

## 1. 准备项目与设备

项目用于组织设备、数据和规则。已有项目时先确认当前项目；需要新项目时，在项目管理中创建：

1. 输入项目名称。
2. 选择页面允许创建的区域。
3. 提交后核对项目列表，并确认或切换到目标项目。

在“所有设备”中选择“创建设备”，填写设备名称与设备标识。设备标识创建后不可修改，用于 MQTT Topic。

设备类型用于定义属性、事件和命令等物模型，创建设备表单中的类型选择为可选项。需要使用物模型校验时，请先按该部署的建模说明完成类型配置、发布及绑定要求，不要假设任意属性都能被接收。

## 2. 保存设备密钥

在设备列表打开目标设备的“凭据”入口，选择“生成新密钥”。立即复制并安全保存显示的密钥，然后勾选已保存的确认项。

密钥明文只显示一次，关闭弹窗后无法再次查看。不要将密钥放入日志、公开代码或截图；作废后的凭据不能继续用于设备认证。

## 3. 按协议连接

使用部署方提供的连接地址、端口和 TLS 配置连接 MQTT。用户名格式为 `{projectKey}/{deviceKey}`，密码使用该设备的密钥。

按接入协议准备属性上报消息，并核对 Topic、消息标识、采集时间和属性字段。连接成功后发送消息，再检查数据是否被接收；连接建立本身不代表数据已入库。

若缺少连接参数、设备标识或协议说明，先向部署方取得信息。认证或权限校验被拒绝时，核对项目、设备、凭据和权限配置，不要尝试通过更换 Topic 绕过限制。

## 4. 核对设备数据

在控制台打开对应设备的数据入口，核对上报属性与历史曲线。若没有预期数据，请检查所选项目、设备、查询时间范围及上报消息是否符合该部署的协议与物模型要求。

完成数据核对后，再按业务需要了解远程控制和规则能力。
