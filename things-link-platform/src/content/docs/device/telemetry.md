# 属性事件与历史数据

设备详情将当前属性、原始历史、数值曲线与事件分开显示。选择数据时同时核对设备、属性、模型版本和时间范围。

## 当前值与历史

Reported 展示设备已上报状态。较晚到达的旧数据可能保留在历史中，但不能覆盖已经更晚的当前状态。发生时间是设备采集时刻，接收时间是平台看到消息的时刻，接受顺序用来解释平台处理先后。

历史来源用于区分真实采集、模型版本和可用顺序事实；显示未知表示未提供对应元数据，不是属性无效，也不应猜一个来源。数值曲线只画真实点，空图不补零或虚构趋势。

## 原始属性历史

选择属性、模型及时间范围查询原始明细。文字、布尔、对象和数组不一定能用数值曲线表达，应查看原始值和质量事实。套餐限制可读历史窗口，时间超出窗口不能当作设备从未上报。

列表有数据时显示分页。后续页复用返回游标；筛选变化重新从第一页查询。更换项目、设备或身份时，旧结果不能继续展示为新对象数据。

## 独立事件

事件有事件标识及参数，按设备绑定模型定义校验。MQTT 事件 Topic 为：

```text
tc/v1/{projectKey}/{deviceKey}/up/event/{eventKey}
```

正文包含 `messageId`、`modelVersion`、`occurredAt`、`params`。事件不是属性；当前事件路径不提供子设备代报。事件历史查询读取真实事件事实，旧日志不自动转换为事件历史。

## 核对顺序

先在消息日志确认输入，再对照当前值与原始历史，最后检查图表及业务动作。实时连接已建立只代表更新通道；页面恢复后补读权威状态，不能把增量消息当作唯一数据。

控制操作参见[命令与期望状态](/docs/device/commands)，应用显示参见[看板](/docs/business/dashboards)。
