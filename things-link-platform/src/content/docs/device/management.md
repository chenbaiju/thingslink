# 设备管理与消息调试

“所有设备”用于查找设备和打开详情。查询以服务端游标分页，不推算总条数；修改筛选或页大小后从第一页重新查询。

## 筛选与查看

按名称或标识、设备状态查询，展开后添加设备类型、组等条件。重置会恢复筛选。点击设备进入详情，先核对设备 ID 与当前项目，再查看所需页签。列表某项状态不可用时显式重试，不把读取失败解释为设备正常。

## 档案标签与分组

设备详情通过“编辑信息”修改允许的档案字段。设备标识创建后不可修改；已绑定模型的类型和版本受额外约束。信息中的标签键在单台设备内唯一，动态设备组按最新标签事实匹配。

设备组分静态与动态两类。创建后类型不可改，避免静态成员被错误解释为动态结果。选择组执行任务时，执行记录保留当次目标，不以后来的组变化改写过去结果。

## 坐标与安装说明

概览中的坐标采用 WGS84，经度在前、纬度在后。当前坐标与安装位置说明分别保存；文本位置不是坐标，也不从其自动推断 GPS。空坐标只表示尚无对应记录。

## 消息日志

进入“消息日志”，按设备、类型和时间查询，查看方向、协议、追踪信息及失败原因。原始记录可能被脱敏、截断或受保留期限制，日志中的秘密不能用于恢复凭据。

短期订阅票据工具仅生成调试连接参数，不自动连接。票据最长五分钟、秘密仅显示一次，未使用也占共享额度；不要把票据放到 URL 或长期存储。

## 完成检查

使用同一设备身份核对档案、模型绑定、接入配置和消息事实。有连接而无属性时，从[遥测与历史](/docs/device/telemetry)查模型、时间和输入，再看[故障排查](/docs/operations/troubleshooting)。
