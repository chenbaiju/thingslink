# 应用目录与终端访问

应用连接发布配置、看板和终端访问入口。当前终端采用 WebApp 路线，管理接口可用不等于已交付原生手机 App。

## 创建应用

打开“应用与看板 → 应用管理”，先查看应用目录，再填写创建表单。应用目录名称用于管理，允许按独立改名操作修改，不应与发布内容或终端显示名称混用。

打开应用后读取草稿，配置页面、看板等当前支持项，保存并核对草稿版本。读取失败时显式重试，不能用空内容替代远端草稿；本地输入不应自动覆盖未知版本。

## 发布与访问

保存和发布分开。发布前检查看板引用、能力开关和目标用户；发布后在对应 WebApp 宿主查看实际版本。宿主与版本化客户端合同必须兼容，旧宿主被拒绝时先更新部署制品。

用户只看到其当前有权读取的资源。登录终端应用不自动授予项目管理角色，项目成员也不会自动成为所有终端设备的所有者。

## 生命周期检查

重命名核对目录变化；发布核对发布版本；授权核对用户身份；删除核对当前结果与保留记录。这些动作分别验证，不用目录里有一行证明整个应用可用。

应用入口、域名和可访问网络由部署方提供，内部白名单仍适用。不要把参考产品中的 OEM、原生客户端或自定义域名操作移植为本平台已提供服务。

权限准备见[终端用户](/docs/business/end-users)，组件设计见[看板设计与发布](/docs/business/dashboards)。
