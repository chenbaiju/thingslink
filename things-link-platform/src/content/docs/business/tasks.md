# 任务调度

任务按时间调度设备命令，可以面向项目全部设备或设备组。创建计划前，确认目标设备有命令模型与可用控制权限。

## 创建任务

进入“规则与自动化 → 任务调度”，点击“创建任务”。填写任务名称、说明和启用状态，选择一次性或周期，再配置目标范围、命令标识和 JSON 参数。

一次性执行时刻按浏览器本地时间选择，提交时转换成 UTC。周期表达式由秒、分、时、日、月、星期组成，按页面显示的项目时区解释。不要直接套用只有五段的系统 crontab 示例。

使用设备组时核对静态成员或动态条件。动态组在每次执行创建时按设备事实冻结匹配结果；以后修改标签或组定义不能改变既有执行目标。

## 先测试一次性

选择教学设备和无副作用命令，安排一个未来时刻，保存后核对任务状态和时区。触发后查看执行记录中的目标与各项结果，再检查设备命令回复。只有验证通过后再启用周期计划。

## 编辑和停用

编辑、停用或删除按当前状态执行。已有执行事实保留；关闭页面不会取消服务端任务，也不能撤回已受理的命令。创建响应未知时先核对列表和原操作。

## 排查未执行

依次查启用状态、时间解释、目标快照、命令模型、设备协议、权限与额度。任务计划触发、命令受理、设备回复是三个检查点，不用列表更新时间代替执行时间。

与单设备属性/时间触发动作的差别见[自动化](/docs/business/automation)。
