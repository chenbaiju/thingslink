# 套餐额度与用量

套餐定义可用能力和额度，有效额度由订阅、资源包及允许的调整共同决定。当前内部使用仍计量，不因为隐藏收费入口获得无限额。

## 阅读套餐目录

“账号与平台工具 → 套餐与权益”按目录比较版本、功能和数量。产品修订是不可变事实，调价或调额需要新修订。页面参考价与销售状态不代表当前环境已开通真实支付或自动购买流程。

## 租户池与项目贡献

项目设置中的“用量与额度”区分项目贡献和租户共享池。设备及日用量可能共享，项目成员是当前项目人数；终端用户目录是另一个对象。新增项目或 API Key 不会凭空扩大共享池。

| 读数 | 应如何理解 |
| --- | --- |
| 已使用与有效额度 | 同一统计口径和窗口比较 |
| 当前项目贡献 | 当前项目消耗，不是租户所有项目明细 |
| UTC 日计量 | 日窗口按 UTC 边界，不按浏览器日历猜测 |
| 保留期与可读窗口 | 可查询历史范围，不能等同对象已经物理删除 |
| 读取不可用 | 资格或服务状态未知，不显示成零或无限 |

## 超额处理

出现超额拒绝时先确定资源类型、窗口和共享池，再检查已创建的资源及订阅状态。只有明确授权的维护操作才可调整；不要通过换 Key、多建项目、跳过 TLS 或绕过租户身份处理额度问题。

保留导出还受存储与访问资格限制。恢复项目或删除业务资源不必然撤回已经计入的日用量，也不能据此改写历史统计。

开发与测试同样使用正常额度合同。故障信息不清晰时携带 traceId 和资源类别排查，不在文档中复制凭据。
