# 项目与成员协作

项目是设备与业务配置的工作区。进入项目后，再操作设备、告警、规则和应用；项目列表、套餐目录和个人中心也可在未进入项目时访问。

## 创建与进入

在“项目与资源 → 添加项目”输入名称，选择允许创建的区域。项目描述可选，最多1000字符，用来说明用途，避免填写密码或秘密。创建后项目列表在名称后显示描述。区域以部署返回的目录为准，不根据示例推定全国或海外区域可用。

“我创建的项目”和“我加入的项目”都支持点击条目进入。核对顶部项目选择器，避免把其他项目数据误当当前项目。

## 邀请成员

有权限的管理员在“项目成员与邀请”点击“邀请成员”，填写邮箱和角色。创建邀请不会立即添加成员；收件人需完成邮箱验证并明确接受。个人中心的“我的项目邀请”用于接受或处理邀请，项目邀请记录用于核对管理员发出的邀请状态。

| 角色 | 主要职责 |
| --- | --- |
| OWNER | 当前项目所有者，不能按普通成员移除 |
| ADMIN | 管理成员与业务配置 |
| OPERATOR | 操作设备和业务数据，不能管理成员 |
| VIEWER | 只读查看 |

同一账号在不同项目可能有不同角色。页面按钮与实际可用权限以服务端当前授权为准。

## 删除与恢复

删除项目后从“项目回收站”检查状态和可用恢复操作。删除不是直接清空历史数据库，也不等于取消已发生的外部操作。恢复、留存导出和到期清理受当前权限、额度与状态约束，先阅读操作提示。

遇到邀请、恢复或删除结果未知，查询原记录并核对身份，不要反复发起新操作猜测结果。资源额度参见[套餐与用量](/docs/business/quotas)。
