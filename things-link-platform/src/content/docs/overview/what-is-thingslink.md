# 认识 ThingsLink

ThingsLink 是一套以 Java 为核心的多租户物联网平台独立实现。设备把数据发送到平台，平台保存设备事实、执行配置好的规则并向应用提供受权数据。控制台负责项目配置和运维，WebApp 承载发布后的终端应用，官网提供介绍和使用文档。

## 平台解决什么问题

同一项目可以管理设备身份、物模型、网关关系和设备组，查看当前属性、历史、事件及命令结果，再基于这些数据配置告警、自动化、任务或看板。后端通过项目权限和租户隔离限制访问，设备身份与控制台账号分开认证。

```text
设备或网关 → 认证与协议接入 → 属性与历史事实
                               ↓
                  告警、消息规则、自动化、任务
                               ↓
                   控制台、看板、应用、系统集成
```

## 主要能力

| 领域 | 使用方式 |
| --- | --- |
| 设备接入 | MQTT、HTTPS、TLS TCP、DTLS CoAP；各协议能力范围不同 |
| 数据管理 | 当前值、期望值、原始属性历史、数值曲线、事件历史和位置 |
| 业务处理 | 固定数值告警、顺序消息规则、属性或时间触发自动化、手动场景、命令任务 |
| 应用与集成 | 版本化看板、WebApp 应用、终端用户授权、API Key、签名 Webhook |
| 运维 | 配额与用量、消息与执行记录、受控 OTA、只读 Agent 证据及事实报告 |

平台接收消息、设备执行动作、收件人收到通知是不同结果，应分别检查对应记录。

## 当前范围

当前用于公司内部服务器及来源 IP 白名单接入。额度、计量、权限、TLS 和审计继续生效。模型辅助诊断需要独立准入；SIM、商用云和公开站点部署验收暂停。原生 iOS、Android、微信小程序及 OEM 服务不在本指南中承诺。

本项目与同名商业服务不是同一系统。商业服务文档仅作为学习路径参考，接口、协议、价格和功能以本项目部署版本为准。
