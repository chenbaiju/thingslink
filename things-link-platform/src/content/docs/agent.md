# Agent 运维助手

运维助手在控制台内复用现有登录与项目权限，帮助你整理设备排查证据、查询项目知识并生成事实报告。当前提供只读能力，大模型辅助诊断待开放。

## 查看设备证据

登录控制台并选择目标项目，在设备详情打开“诊断证据”页签，手动加载属性目录，选择需要查看的属性。也可按页面提供的时间范围查询历史数据，并分页查看告警。

核对采集时间、来源和缺失提示：没有数据不代表设备正常，历史数据也不代表设备此刻的状态。

## 检索项目知识

在项目设置中查看项目知识。管理员明确批准的内容可供当前有权的项目成员查询；检索结果附带版本及原文引用，便于核对依据。

当前使用字面检索，不是语义问答。未命中时可以调整关键词，或请管理员补充适用资料。

## 保存个人记录与生成报告

在“诊断证据”页签的“个人事实记录”区域，手动保存证据，再选择一条记录生成事实报告。报告可查看和下载；项目设置还支持从本人记录中选择最多五台设备，每台设备一条来源，生成集合事实报告。

记录默认仅本人可见，读取和下载仍需具备当前项目权限。来源到期、删除或权限被撤销后，不再提供相应记录与报告。下载后的文件请自行妥善保管。

报告汇编所选历史记录，展示来源、时间和缺项，不调用大模型，也不对当前设备健康作出诊断。未选择的设备不在报告覆盖范围内。

## 当前能力边界

- 大模型辅助诊断尚未开放，填写或启用模型 Key 不代表已经可以使用。
- 不提供自动巡检、定时报告、自主规划或多 Agent 协作。
- 运维助手不下发设备指令，不设置属性，也不确认或解除告警。

需要准备项目与设备时，请参阅[快速开始](/docs/getting-started)。
