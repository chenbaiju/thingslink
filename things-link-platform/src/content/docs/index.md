# ThingsLink 文档

这里汇集当前已有的接入准备资料，帮助你了解项目与设备的基本操作。

## 快速导航

- [快速开始](/docs/getting-started) — 准备项目、设备和密钥，了解连接前提与数据核对步骤。

- [Agent 运维助手](/docs/agent) — 查看排查证据、检索项目知识并手动生成事实报告。

快速开始介绍准备流程；连接前还需取得对应部署的接入参数和协议说明。

## 什么是 ThingsLink？

ThingsLink 提供设备接入、数据采集、远程控制与规则告警能力。具体设备、权限和配置需按实际部署核对。

| 用途 | 产品介绍与文档 | 设备管理与运维 |
| 需要登录 | 否 | 是 |
